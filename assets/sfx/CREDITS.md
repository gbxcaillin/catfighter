# Sound effect credits

Every clip in this folder is cut from a pack published on [OpenGameArt.org](https://opengameart.org)
under **CC0 1.0 (public domain)**. No attribution is required; this file records where each sound came
from so any of them can be traced or swapped.

The clips are built by `tools/build-sfx.sh` (trim silence, normalise to -1 dB, mono 44.1 kHz mp3).
The source file is `https://opengameart.org/sites/default/files/<download>`.
